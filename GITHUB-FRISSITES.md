# GitHub-frissítés – v1.3.1

Repository: https://github.com/hajgre/menekules-a-diktator-elol

1. Készíts biztonsági mentést: **Code → Download ZIP**.
2. Csomagold ki a `MENEKULES-A-DIKTATOR-ELOL-GitHub-Pages-v1.3.1.zip` fájlt.
3. A GitHubon töltsd fel a 4 játékfájlt a repository főmappájába: **index.html**, **styles.css**, **game.js**, **questions.js**. Ugyanezeket a régi fájlokat cseréld, ne alkönyvtárba tedd őket.
4. **Commit changes**. A GitHub Pages beállításai maradjanak: `main` / `/(root)`.
5. Nyisd meg: https://hajgre.github.io/menekules-a-diktator-elol/?v=131
6. Játssz el az első kérdésig, válassz egy választ. A visszajelzés után kb. 3 másodperccel Enter nélkül folytatódjon a játék.

**Nem kell új repositoryt létrehozni. Nem kell a böngészőben tárolt mentéseket vagy rekordokat törölni.**

## Visszaállítás

Ha nem megfelelő a frissítés, a biztonsági mentésből a korábbi `index.html`, `styles.css`, `game.js`, `questions.js` fájlokat töltsd vissza ugyanoda, és ismét Commit changes. A böngésző helyi adatait ne töröld.

**Korlát:** az élő GitHub-verziót nem sikerült közvetlenül beolvasni; a helyileg meglévő v1.3.0 kiadás alapján dolgoztunk. Az éles közzétételt csak a feltöltés után ellenőrizhetjük.
